- **L38-40 现文**：`【禁止参数解构】：必须使用单一名命对象参数。❌ async readFile({ path, encoding }) ✅ async readFile(payload: { path, encoding })`

### [WRONG] three-roles.md L228：沙箱后端方言写成 errno 码，源码实际是 stderr 签名串

- **现文**：`后端方言：EROFS/bwrap、EACCES/Landlock、EPERM/Seatbelt；Windows ACL 属 partial（硬链接/读不受限/AppContainer 边界）`

- **应为**：`后端方言（stderr 签名）：bwrap "read-only file system"、Landlock "permission denied"、Seatbelt "operation not permitted"、Windows ACL "access is denied"/"access to the path"/"permission denied"/"operation not permitted"；Windows ACL 属 partial（NTFS 硬链接别名、读不受限、AppContainer 包 SID 边界）`
- **证据**：dsh-sandbox-local/lib/index.js（DENIAL_SIGNATURES 常量，约 L205-225；Windows ACL partial 注释约 L85-96）；dsh-sandbox-windows-acl/README.md（"The guarantee stays partial: hard links alias file objects and files ACL'd by another AppContainer tool stay unreadable."）。
